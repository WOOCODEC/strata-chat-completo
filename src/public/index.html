Atajos

  • Enter envia · Shift+Enter salto de linea
  • Ctrl+V o arrastra para adjuntar una imagen o un PDF
  • De un PDF se lee el texto en tu PC: la IA recibe ese texto, no el archivo
  • «Leer en voz alta» en cada respuesta · Esc para parar
  • La voz y la velocidad de lectura (100% a 200%) se cambian aqui
  • «Copiar respuesta» y «Copiar bloque» en cada mensaje
  • Doble clic en el titulo para renombrar
  • El panel se puede ocultar con «Ocultar»
  • Si un dato sale «–», mira «API local»: toca reiniciar el servidor
